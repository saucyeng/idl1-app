## Do (commit after every task)
1. `idl-rs docs wire --out <dir>`: for each binary format (IDLH, tile IDLR, IDLS, IDLG, raster),
   encode one small deterministic fixture (synthetic samples, fixed seed, every header field
   exercised incl. `axis_kind` both values for IDLH) and write `<format>-v<N>.bin` plus
   `<format>-v<N>.json` (the decoded expectation: header fields and the first/last few values
   with the exact numeric type). Deterministic bytes: same output on every run and platform
   (little-endian, no timestamps).
2. Commit the generated set under `app/src/ipc/golden/`; a vitest per format loads the `.bin`,
   runs the TS decoder, and deep-equals the `.json` (header + samples). A format the TS side
   does not decode yet (if any) gets a test that asserts the header version only, with a
   `TODO(idl0):` naming the missing decoder.
3. CI: a step regenerating `app/src/ipc/golden/` and `git diff --exit-code` on it, next to the
   other freshness steps; `docs/CI.md` paragraph.
4. CHANGELOG `[docs]`; C3 §1 sentence: "every binary format has a committed golden fixture
   generated by the engine and decoded in the app's tests" (spec-during, in the app worktree).
