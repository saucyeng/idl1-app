## Rulings (R230; do not ask)
1. **Grammar** `idl-rs <noun> <verb> [args] [--flags]`. Nouns: `session | workbook | track |
   catalog | library | device | docs`. Verbs: `list | show | new | check | eval | set | import |
   export | scan | fold-in | index | rebuild | verify | delete`. A test enumerates every
   registered subcommand and fails on any noun or verb outside these lists.
2. **One command table.** Introduce `rust/core/src/commands/table.rs` (or `cli/src/table.rs` if
   core must stay free of it; say which and why): every CLI command as a row {noun, verb, args,
   flags, core fn, json shape name, help, tier}. Clap subcommands are generated from the rows
   (a macro or a builder over the table), and `idl-rs docs cli` emits the table as Markdown for
   the generated reference. The TS `commandTiers.ts` stays the UI's table; a test in each repo
   asserts the two agree on the shared ids (export the Rust table as JSON via `idl-rs docs cli
   --json`; the app test reads the checked-in copy `app/src/shell/cliTable.json`, regenerated by
   CI like the reference). This is the seed of R228.2's agent tool schemas; do not build the
   schemas yet.
3. **Uniform behaviour** on every command: `--json` (shape = the C3 DTO where one exists, plus
   `schema_version: 1`), `--data-dir` or `IDL1_DATA_DIR`, exit 0/1/2, typed JSON errors on stderr
   in JSON mode, `--dry-run` on every writer, idempotent where the operation allows.
4. **Verbs to add**: `session list [--venue --track --since --until --tag] | show <id> |
   set-start <id> <utc_ms> | set-meta <id> [--venue --track --bike --notes --tag…] | import
   <file>` (top-level `import` becomes a deprecated alias printing a one-line notice);
   `workbook new --template <name> --session <id> | check <file> | eval <file> --session <id> |
   cells <file>`; `chart data <file> <cell>` lives under `workbook data <file> <cell>` (chart is
   not a noun); `report <file> --out` becomes `workbook export <file> --report <out.html>`;
   `track list | detect <session>`; `session laps <id>`; `catalog verify | rebuild`. Existing
   `library` verbs keep their names. If a verb needs a core function that does not exist, add
   it in core with tests; if it needs a design decision (e.g. what "template" means for
   `workbook new`), escalate with a proposal.
5. Spec-during: a new `docs/superpowers/specs/2026-09-11-idl1-c6-cli.md` (C6) recording the
   grammar, vocabularies, uniform behaviour and the table's row shape; CHANGELOG `[docs]`.
